# Laboratorna-IPZ
# Виділення колірних каналів RGB (Lab1_Motruk_AM231)

Навчальний Windows Forms застосунок на мові C# для розкладання растрового зображення на три базові колірні канали (Red, Green, Blue).

## Функціонал
- Завантаження зображень у форматах `.bmp`, `.jpg`, `.png`.
- Попіксельне виділення каналів **R**, **G** та **B** за допомогою класу `Bitmap`.
- Відображення оригіналу та трьох результуючих зображень у вікні програми.
- Автоматичне збереження каналів у папку з оригінальним файлом (`Motruk _AM-231_R.bmp`, `_G.bmp`, `_B.bmp`).
